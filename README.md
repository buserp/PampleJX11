# PampleJX11

This repo is my take on the classic [JX11 synth, as documented by The Audio Programmer](https://www.theaudioprogrammer.com/books-and-courses/synth-plugin-book).

It modernizes some of the conventions in the book (mostly using`constexpr` instead of magic numbers), and uses the fantastic [Pamplejuce](https://github.com/sudara/pamplejuce) for cross-platform compilation. No more Projucer required!
